# 练习页交互翻新 · 设计文档

日期:2026-08-11
范围:`bin/keymap_template.html` 练习区(CSS + JS)、`custom/keymap.yml` 的 `practice.ui` 文案段
不动:生成器架构(`bin/keymap.py`)、其余四个视图、`entry.signal` 判定原理、`dStats` 存储结构

## 背景与问题

练习页现状有四个问题:

1. **考试模式是坏的**:`pickNext()`(模板 :800 附近)只有前置过滤,函数体遗留未填的
   `TODO(human)`,返回 `undefined`,点「开始考试」直接跳 0/0 空报告。
2. **闪卡答法蠢**:无法真按判定的题(输出会切走浏览器的,如 `⌃Tab`)要求手打
   「cmd+shift+l」这样的文字答案,又慢又容易格式错。
3. **自由模式没有目标感**:纯沙盒 + 静态提示清单,没有引导、没有进度、练不起来。
4. **视觉/布局差**:题目纯文字呈现不直观,对错反馈太弱,舞台+侧栏层级拥挤,整体
   缺少「练习工具」的仪式感。

## 方案选择

**方案 A(采纳):在现有模板内重构练习区。** 只动练习页相关的 CSS/JS 与 keymap.yml
文案,单文件自包含的产物形态不变。

- 方案 B(否):练习页拆独立 JS/CSS、构建时内联——为一个页面改构建链路,收益不配成本。
- 方案 C(否):只修 pickNext 和闪卡——达不到用户确认的范围。

## 设计

### 1. 自由模式 → 闯关清单

- 右侧栏从静态提示清单改为**本轮清单**:每项 = 键帽渲染的组合键 + 中文标签 +
  ○/✓ 状态。按对点亮(绿色脉冲动效),顶部进度条 `N/M`,全点亮出完成动效和
  「再来一轮」按钮。
- **只有 text 类条目计入进度**(浏览器能收到信号的)。闪卡类灰显挂「闪卡」标签
  (提示去考试模式练),鼠标类灰显挂「鼠标」标签,两者都不计数。
- 实时解码从侧栏移到主舞台文本框下方一行:按错时也告诉你刚才实际触发了什么。
- 选中鼠标组时保留点靶子沙盒,交互不变。
- 清单点亮状态是会话内存,不落 localStorage;「再来一轮」清零重来。

### 2. 考试模式:修复 + 三种题型

**抽题(pickNext,生疏度加权)**:权重 = 没练过 > 错误率高 > 平均耗时长,加少量
随机扰动避免每轮顺序雷同。输入输出契约不变:`(pool, asked) → 题 | null`。
该函数保留为实现阶段的人工贡献点(它本来就是遗留的 TODO(human))。

**文本题**(真按判定,保持原理):

- 按出**带修饰键但不匹配**的信号 → 舞台红闪 + 抖动,并显示实际触发了什么;
  普通打字(无修饰键)不惩罚不提示。
- 「看答案」后该题记错,展示键帽渲染的答案,按 `空格` 或 `回车` 进下一题。

**闪卡题**(Anki 自评流):

- 正面只有题干;`空格` 或点按钮**翻面**看答案(键帽渲染,同时给出实际输出信号)。
- 翻面后 `1` = 记得(计对)、`2` = 忘了(计错),也可点按钮。
- 自评结果直接映射 `dStats` 的 ok/fail,存储结构 `{n, ok, ms}` 不变,老数据兼容。

**鼠标题**:点一次靶子过题,交互不变,只跟随新视觉。

**反馈与进度**:

- 侧栏进度从文字改为**点阵**:每题一个点,绿=对、红=错、空心=未答,当前题高亮。
- 答对绿色脉冲、答错红色抖动(CSS keyframes,无 JS 动画库)。
- 报告页沿用 结构(得分大字 + 生疏清单),生疏清单改键帽渲染。

### 3. 视觉

- 新增 **combo→键帽渲染器**(JS):把 `✧⇧H` 这类串解析成一排 `<kbd>` 键帽,
  题干答案、闯关清单、报告、翻面统一使用。解析复用现有 `normCombo` 的分词逻辑。
- 舞台重排:题型标签 + 大号题干居中,操作按钮沉底;组选择 chip 条保持功能但降低
  视觉噪音(缩小、去边框感)。
- 沿用页面现有 CSS 变量与设计语言,只做练习区内的精致化;不引入任何外部依赖。

### 4. 配置与硬约束

- 所有新增中文文案(翻面/记得/忘了/清单标题/完成语/灰显标签等)一律进
  `custom/keymap.yml` 的 `practice.ui`;模板里零渲染中文——仓库铁律。
- 废弃的文案键(如手打答案的 `answer_placeholder`、`check`)从 keymap.yml 删除。
- `practice.kinds` / `block_signals` / `focus` 配置语义不变。

### 5. 错误处理

- 选中的组全是闪卡/鼠标类时,自由模式清单显示空态提示(去考试模式练),不报错。
- `dStats` 里存在已删除键位的旧 id:照常忽略(现状行为),不迁移不清理。
- 键帽渲染器遇到解析不出的片段,原样输出文字,不吞字。

### 6. 验证

`make keymap` 重新生成后浏览器人工过一遍:

1. 自由模式:点亮流程、进度、完成动效、再来一轮、灰显条目、实时解码、靶子。
2. 考试模式:三种题型各答对/答错/看答案一次,点阵进度,报告,生疏清单。
3. 抽题:错过的题在下一轮明显更容易被抽中。
4. 组切换、配置切换、旧 localStorage 成绩兼容。
